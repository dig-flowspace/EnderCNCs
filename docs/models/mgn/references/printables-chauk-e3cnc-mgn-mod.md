# E3CNC MGN MOD ALT (THREADED ROD) (VERSION 2)

## Short Description
Remixed E3CNC MGN Mod with Threaded rods by Ravenkeeper. Original Creator: https://www.printables.com/@Tony_409529
## Description
**UPDATES VERSION 2 (Tested)**
- Returns to standard tool mounting to maintain compatibility of the original designs tool heads and bearing plates.  
- Added a hole for allowing the X Axis rod extend past the Gantry.  
- QOL improvements.  
- Bottom side gantry support mounting added.  
  
**UPDATES: 5/26/26 (Tested)**  
- Add more alternate options.   
- X Axis rod opening  
  
**UPDATES: 4/21/26**  
- Fix Widened D2F-L by 0.3mm. Issue exists on the corner blocks only. All other parts were unaffected. Both 350mm and 360mm corner blocks were addressed. A couple passes of the DF2-L on a flat piece of sand paper will be all it needs if you printed prior to 4/21/26.  
  
**This mod is a remix of the original MGN MOD with a few changes.**
- Adapted for 350MM MGN Rails
- Adjusted Rail Positioning
- Shuffled End-stops location to reflect changes made to carriages.
- Added Addition End-Stop locations for boards that support it.
- Two threaded nuts per Axis with both 3mm and threaded inset options on all axis.
- Moved X Axis cable chain to allow for a mounting position on the Y gantry.
- Measurements were confirmed with data/spec sheets and referenced the original E3CNC CAD for tolerances.
- Moved Z Axis forward 2mm (to compensate for Z Axis threaded rod connection change, needed extending backwards by 2mm).
- Updated 52mm and 65mm 3D printed Spindle mounts to match New Z Axis Position.
- Updated 52MM Spindle clamp mount (for the metal clamp that comes with many 52mm Spindles and spindle kits).
- Added Subframe support and work holding options (will require extra extrusion. 1x 400mm 4020 cut to length (~360mm) and 2x 300mm 4020 can be left at 300mm).
- Includes some test 3D prints for spacing and sizing of MGN12 carriages, vertical and horizontal holes, threaded rod connections, and Z carriage rail spacing for the main X extrusion.
- Added alternative Y/Y1 Gantry pieces that lower the print time by a smidgen.
- Added alternative front corner blocks for 360MM rails.
- I made it pink.

Notes:
- Due to the 2mm offset change on the threaded rod this is not compatible with the original tool mounts.
- Don't forget to check tolerances with the test prints!  
- There is no official BOM for this build.   
  
For rails and rods not included:  
2x 450mm TR8x8 Threaded Rod for Y and Y1 ~444mm  
1x 350mm TR8x8 Threaded Rod for X ~320mm  
2x 350mm MGN12H Linear Rails (or 360mm rails if you can find them)  
1x 300mm MGN12H Linear Rails  
All together you will need:  
6x MGN12C Carriages   
6x MGN12H Carriages  
Along with required hardware in the original build BOM.  
Plus you will need extra M3x8 and M3x10 to attach the linear rails to the extrusion and nuts for the threaded rods as well as attaching the carriages to their gantry.
